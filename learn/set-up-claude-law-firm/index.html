How do I set up Claude for my law firm?

By Jordy Backes Published 2026-09-02 Facts checked 2026-08-30

Answer

Decide who owns the account, pick a plan the firm controls or a personal plan one person owns, turn off model training on any personal account, and install the desktop app. Point its Code tab at one working folder, write three firm rules down, and run the first task on a fictional matter. A licensed attorney reviews every output.

[ The short version ]

  • The first decision is ownership: a Team or Enterprise plan belongs to the firm, a Free, Pro or Max plan belongs to one person and that person's settings.
  • On personal plans the training choice is a toggle called Help improve our AI models. Turn it off before any document goes in, and write down the date.
  • The desktop app carries Chat, Claude Cowork and Claude Code in one place; the builds on this site run in the Code tab, and nobody writes code there.
  • One working folder holds everything Claude reads and writes for the firm: the positions file, the test matter, the drafts.
  • The first run touches no client data: a fictional matter, one real task, and a licensed attorney reading what came back.

Most setup guides for Claude start at the sign-up form. A law firm’s setup starts one step earlier, with a question about ownership, because the account that holds the settings is the account that holds the firm’s confidentiality posture. This page walks the whole setup in order, from the ownership decision to a first test that touches no client data. Every price and every setting was read on the date at the top, and the sources sit at the bottom.

Step zero: who owns the account

On a personal plan the account belongs to a person, and so do its settings and its history. On a Team or Enterprise plan the account belongs to the firm, the firm sets the settings, and Anthropic states that customer data on its commercial plans is not used for training by default. That difference matters more than any feature.

The table gives the plan picture as read on the facts date. The cost question in full, seat by seat, is a page of its own: How much does Claude cost for lawyers?

A firm of two or three lawyers usually ends up in one of two places: a Team plan the firm owns, or one personal plan owned by the partner who will run the setup, with the settings treated as firm settings. Either works for the first test. What does not work is five personal accounts nobody at the firm controls.

The setup, step by step

Seven steps, in order. Steps 1 and 2 settle the data posture, then the app goes on the computer, then the setup becomes the firm’s.

  1. 01

    Decide who owns the account, in writing

    A personal plan belongs to one person: the settings, the history, the login. A Team or Enterprise plan belongs to the firm, and on those plans Anthropic states customer data is not used for training by default. A Team plan needs a minimum of two members. For a first test, one person on a personal plan is enough, as long as the firm owns that person's settings.

    Result: The firm knows which terms apply before anything goes in.

  2. 02

    Create the account and set the training toggle

    On Free, Pro and Max the toggle is called Help improve our AI models, under Privacy. New accounts pick a preference during signup, so open the page anyway and confirm where it stands. The direct route is claude.ai/settings/data-privacy-controls. Note the date you checked it.

    In the app: Your name (settings menu) → Settings → Privacy → Help improve our AI models → off

    Result: Anthropic states that new chats and coding sessions will not be used for future model training.

  3. 03

    Install the desktop app

    The download page is claude.com/download. The app carries Chat, Claude Cowork and Claude Code in one place. Chat is available on every plan including Free; Claude Code and Claude Cowork are available on Pro, Max, Team and Enterprise. The builds on this site run in the Code tab, and nothing about them involves writing code.

    Result: The app is open on the Code tab, on a paid plan.

  4. 04

    Make one working folder and point the app at it

    Create a folder on the computer, named for the firm or the practice group. In the Code tab, choose it as the working folder. Everything Claude reads and writes for the firm lives in that one folder from now on: the positions file, the fictional test matter, every draft. Keep everything Claude should read inside that folder.

    Result: The folder name shows in the label above the message box.

  5. 05

    Write three rules down before the first real matter

    Who owns the account. Which documents may go in, and which never do. Who reviews every output before anyone relies on it. The checklist below is the template; the answers fit on one page.

    Result: A one-page AI rule the firm can show a client who asks.

  6. 06

    Build a fictional matter and run one task

    Paste the first-folder prompt below into the Code tab. It writes a fictional matter and a draft positions file into the folder, and drafts nothing else. Then run one real piece of firm work on those files. A contract review is a good first task, because a redline is easy to judge against your own.

    Result: A real workflow tested on no client data. Review-ready, never send-ready: a licensed attorney approves everything before it leaves the firm.

  7. 07

    Save the instruction you keep retyping

    The second time you paste the same instruction, ask Claude to save it as a skill file in the folder. From then on the task is one typed command, and it runs the same way for almost everyone who opens the folder.

    Result: The same task runs the same way on almost every run.

The three rules, on one page

Before a real matter goes in, the firm should be able to answer three questions in writing, plus one date. Each item links to the step that settles it.

[ Checklist ]

The three written rules, plus one date

  • Account owner. Whose name is on the account, and under which terms it runs. Step 1 decides this.

  • Allowed documents. Which document types may go into the tool, and which never do. Until the firm writes that list, every test stays fictional. Step 6 keeps the first run fictional.

  • The reviewer. Who at the firm reads every output before anyone relies on it. One named person.

  • The toggle date. The day someone confirmed the training toggle was off, and on which account. Step 2 sets it, with the exact route.

Write the answers down. A setting that lives in one partner’s memory does not survive a busy week, and a client who asks how the firm uses AI deserves a written page.

The first task, on a fictional matter

The first run should touch no client data at all. It still tells the firm what it needs to know, because the workflow is real even when the matter is invented. This prompt runs in the Code tab, inside the working folder, and does two things: it writes the fictional matter as files, and it drafts a positions file for a lawyer to correct. It drafts nothing else.

With those files in the folder, run one real piece of firm work on them and hand the output to the reviewer named in the rules. A contract review is the recommended first task: the redline is easy to judge, and the whole run, with its counts and its honest limits, is documented on Can AI review a contract?

Where setups go wrong

Three things the build videos on this site and the help pages agree on:

  • The toggle’s name. The help article and the screen have not always agreed on the toggle’s exact name, so step 2 carries the on-screen name from the build video. Confirm it on your own screen and write down the date.
  • The folder is the boundary. Claude reads what is in the working folder, so a client file dragged in by mistake is inside the tool. The allowed-documents rule exists for that moment.
  • Retyping is the ceiling. By the third time someone pastes the same long instruction, that instruction belongs in a skill file in the folder, so the task runs the same way for whoever opens it.

06 / FAQ

The questions, answered

Do I need the Team plan to start?

Not for the first test. One person on Pro or Max can run the fictional-matter test, as long as someone at the firm owns that account's settings and the training toggle is off. For client work, most firms want a plan the firm controls; Team needs two members and ran $20 or $25 a seat a month when this page was last checked.

Do I need to know how to code to set this up?

No. The builds on this site run in the desktop app's Code tab, and the whole interface is typing into a chat and dropping files into a folder. The tab's name does not matter here; nothing on this page writes a line of code, and a lawyer who can use the regular chat can run it.

How long does the setup take?

The account, the toggle, the app and the folder are the short part, and most of that is the ownership decision. The fictional test is the longer part. The real work is the positions file: writing down what the firm accepts and what it pushes back on, which only the firm can do.

What about Anthropic's own legal plugin?

Anthropic publishes a legal plugin that installs in Claude Cowork or Claude Code. On the official pages it carries no separate price and no plan requirement of its own; running it takes a paid plan like everything else in those tabs. The recorded builds on this site use their own skill files instead. Both are plain files in a folder.

What goes in the working folder?

Only what the firm has decided may go in. At setup that means the fictional matter and the draft positions file the first-folder prompt on this page writes. Later it means the positions file the firm has edited and the documents the allowed-documents rule permits. Client files never go in before that rule is written.
